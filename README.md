# Travel Website

## About the Project

Travel Website is a responsive web application developed to showcase travel destinations and provide users with useful information for planning their trips. The project features a modern interface, intuitive navigation, and interactive elements designed to enhance the user experience across different devices.

## Features

- **Destination Guides:** Explore different travel destinations and discover relevant information.
- **Responsive Design:** Adaptable layout optimized for desktop, tablet, and mobile devices.
- **Interactive Interface:** JavaScript-powered elements for a more dynamic browsing experience.
- **Travel Booking Sections:** Dedicated sections for exploring travel packages and booking options.
- **Travel Resources:** Helpful content and recommendations for trip planning.
- **Multi-page Navigation:** Organized sections that make browsing simple and intuitive.

## Technologies & Tools

The project was developed using the following technologies:

- **HTML5:** Semantic structure and content organization.
- **CSS3:** Styling, layouts, and visual presentation.
- **JavaScript:** Client-side functionality and interactive components.
- **Bootstrap:** Responsive layouts and reusable UI components.
- **PHP:** Server-side functionality.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/JhonnFy/Travel-Website.git
```

### 2. Navigate to the project directory

```bash
cd Travel-Website
```

### 3. Run the project

Open `index.html` in your preferred web browser.

**Note:** If you want to test the PHP functionality, run the project using a local server environment such as XAMPP.
